# Day8 최종 모델링 실습 보고서

## 1. 문제와 평가 계획

요청 실행 전에 실패 여부(`failed`: 성공 0, 실패 1)를 예측합니다. 입력은 `input_chars`, `allowed_tools`, `task_type`, `priority`이며, 식별자 `request_id`와 실행 후 값 `failed`, `elapsed_ms`는 입력에서 제외합니다.

고정 train 60건에서 후보를 비교하고 valid 20건은 진단에 사용했습니다. 선택한 설정을 저장한 뒤 개발 80건(train+valid)으로 새 Pipeline을 학습하고 test 20건을 최종 평가했습니다.

후보 순서는 Dummy, Logistic, KNN3, Tree, Forest, XGB, Logistic_FE입니다. 같은 층화 5-fold(shuffle=True, random_state=42)의 평균 F1 최대로 선택하며, 정확한 동점은 후보 순서로 처리합니다. 실패 확률이 0.5를 초과하면 실패로 판정합니다. test를 본 뒤 후보·특성·임계값을 변경하지 않았습니다.

## 2. 지표와 선택 이유

| 후보 | CV 평균 F1 | CV 표준편차 | valid F1 |
|---|---:|---:|---:|
| Dummy | 0.0000 | 0.0000 | 0.0000 |
| Logistic | 0.5219 | 0.2092 | 0.3333 |
| KNN3 | 0.3356 | 0.1764 | 0.5455 |
| Tree | 0.5424 | 0.1236 | 0.3333 |
| Forest | 0.2800 | 0.2544 | 0.2222 |
| XGB | 0.5467 | 0.1046 | 0.2000 |
| **Logistic_FE** | **0.5514** | **0.1897** | **0.1818** |

CV 평균이 가장 높은 Logistic_FE를 선택했습니다. valid F1은 KNN3가 높지만 선택 규칙을 변경하지 않았습니다. 표준편차는 fold 점수의 변동이며 신뢰구간을 뜻하지 않습니다.

| test 건수 | Accuracy | Precision | Recall | F1 | AUC | TP / 실제 실패 |
|---:|---:|---:|---:|---:|---:|---:|
| 20 | 0.7500 | 0.6000 | 0.5000 | 0.5455 | 0.7857 | 3 / 6 |

혼동행렬은 실제 행·예측 열 순서로 `[[12, 2], [3, 3]]`입니다. 실패로 예측한 5건 중 3건이 실제 실패이며, 실제 실패 6건 중 3건을 발견했습니다. AUC 0.7857은 실패를 약 79% 발견했다는 뜻이 아니라 양성·음성 확률의 순위에 대한 지표입니다.

오류 사례 3건은 다음과 같습니다. 전체 5건은 `outputs/error_cases.csv`에 있습니다.

| ID | 실제 | 예측 | 실패 확률 | 해석 |
|---|---:|---:|---:|---|
| R060 | 1 | 0 | 0.099750 | 실제 실패를 놓친 FN |
| R017 | 1 | 0 | 0.379226 | 실제 실패를 놓친 FN |
| R081 | 0 | 1 | 0.589754 | 실제 성공을 실패로 판단한 FP |

실습03에서 train 60건의 같은 5-fold로 회귀를 비교한 평균 RMSE는 Linear **639.83ms**, KNN15 **598.85ms**입니다. 정답은 `elapsed_ms`이고 입력에는 포함하지 않았습니다. 음수 scorer의 부호를 되돌렸으며, fold별 RMSE 평균과 모든 OOF 오차를 합친 RMSE는 일반적으로 같지 않습니다.

## 3. 특성 설계와 군집

`log_input_chars=log1p(input_chars)`는 큰 글자 수의 크기 차이를 줄이고, `chars_per_slot=input_chars/(1+allowed_tools)`는 도구 수를 반영한 글자 수 비율입니다. 두 공식은 같은 행의 입력만 사용합니다. NaN은 유지하고 Pipeline 안에서 학습 자료의 중앙값으로 대체합니다.

파생 특성 추가 후 CV F1은 0.5219에서 0.5514로 올랐지만 valid F1은 0.3333에서 0.1818로 내려갔습니다. 이번 CV 기준의 개선을 확인했지만, 작은 valid에서의 성능 저하도 함께 기록하므로 새 자료에서의 개선을 보장하지 않습니다.

군집은 train 60건의 수치 2열만 사용해 결측 대체·표준화 후 K=3으로 계산했습니다. 중심은 결측 대체 후 원래 단위로 되돌린 값입니다.

| 군집 | 건수 | 글자 수 중심 | 허용 도구 수 중심 |
|---:|---:|---:|---:|
| 0 | 24 | 1542.250 | 4.125 |
| 1 | 19 | 1430.474 | 1.368 |
| 2 | 17 | 444.588 | 2.706 |

silhouette는 표준화 공간에서 **0.4531**입니다. 글자 수와 도구 수에 따른 묶음을 설명할 수 있지만, 정답 없이 만든 군집 번호를 실패 원인이나 위험도 순위로 해석할 수는 없습니다.
